# Miftah Nursyaban — Personal Portfolio

[View Portfolio](https://miftahnursyaban62-dev.github.io/miftahnursyaban62-dev/)

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## ✨ Features

- Responsive design untuk desktop dan mobile
- Dark mode & light mode
- Bahasa Indonesia & English
- Interactive skill cards
- Scroll reveal animation
- Premium project section
- Contact section
- SEO-friendly structure

## 🚀 Run Locally

Clone repository:

git clone git@github.com:miftahnursyaban62-dev/miftahnursyaban62-dev.git
cd miftahnursyaban62-dev

Jalankan local server:

python -m http.server 8080

Kemudian buka:

http://127.0.0.1:8080
